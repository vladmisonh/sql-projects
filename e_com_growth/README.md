# SQL & Data Analytics Challenge

This project simulates a **real-world analytics case**. The goal of this project is to **analyze business performance using SQL & Data Analytics** and deliver **actionable insights** that could help business stakeholders make strategic decisions.

---

## Project Overview

You are working as a **Data Analyst Consultant** for an **e-commerce company** that is experiencing a decline in sales. The business wants to understand **what caused the drop in revenue**, **which areas are underperforming**, and **what actions they should take next**.

You are given **5 relational datasets** (`CSV`) and are expected to:
 - Analyze revenue trends  
 - Perform cohort and retention analysis  
 - Measure marketing effectiveness (ROAS)  
 - Identify high-value customers (LTV & RFM)  
 - Deliver business insights + recommendations  

---

## Dataset Description

| File | Description |
|------|-------------|
| `customers.csv` | Customer profiles (region, acquisition channel, signup date) |
| `products.csv` | Product catalog (category, cost, price) |
| `orders.csv` | Order summary table (date, status, revenue source) |
| `order_items.csv` | Line-level order details |
| `marketing_spend.csv` | Monthly advertising spend by channel |

> **Disclaimer**: All datasets in this project were **synthetically generated using artificial intelligence** for educational purposes. Any resemblance to real businesses or data is purely coincidental. This project does **not** contain real company data.

---
